HR Dashboard Project — Tableau

📌 Overview

Interactive Human Resources Dashboard built using Tableau.
The dashboard provides a complete analytical view of employee information including demographics, roles, locations, salaries, hiring dates, and employment history.

⸻

🎛️ Dashboard Filters

👤 Demographic
	•	Full Name
	•	Gender
	•	Age Group
	•	Education Level

💼 Role
	•	Job Title
	•	Department

🌍 Geographics
	•	Location
	•	State
	•	City

💰 Salary
	•	Salary range slider
	•	Visual salary comparison

🗓️ Employment Status
	•	Status (Hired / Terminated)
	•	Year of Hire
	•	Year of Termination

⏳ Length of Employment
	•	Years of service slider

⸻

📄 Employee List Includes
	•	Employee ID
	•	Full Name
	•	Gender
	•	Education
	•	Job Title
	•	Department
	•	Location (City / State)
	•	Salary
	•	Hire Date
	•	Termination Date
	•	Length of Employment

All values update dynamically based on selected filters.
